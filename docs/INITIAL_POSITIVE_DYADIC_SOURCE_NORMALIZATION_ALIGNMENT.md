# Exact initial normalization for arbitrary positive original dyadic scales

Source: companion T1.4, companion_sections/arithmetic_appendix.tex:139, first-degree-one auxiliary-factor elimination in Step3; T1.5 uses that reduction. Original source hashes remain preserved.

The original-scale alignment obligation is now addressed by an explicit source-box interface allowing ALL four original scales to be arbitrary positive real numbers. The interface retains the actual positive integer source coefficients, the two fixed monomial comparisons, the logarithmic lower bounds, the signed source equation, and the literal finite population. It does not add an individual scale>=1 assumption.

InitialDyadicSourceBox proves that every point of such a population has four positive integer coordinates. If the population is nonempty, its four dyadic upper bounds therefore force every original scale to be at least1/2. The actual normalized Box replaces each scale D by max(1,D), at the SAME source size N, with unchanged lower comparison constant rho and logarithmic margin delta and upper comparison constant8*C. Every field of that Box is proved from the original data: the lower monomials and both logarithmic products increase, and each upper source monomial inflates by at most8.

The integer coefficients are transferred exactly, and the SAME finite population satisfies every normalized signed dyadic bound and the unchanged source equation. In particular no source point is discarded or reconstructed approximately. The original source barrier is bounded by the normalized source barrier, so the literal barrier also transfers without loss. These results are unconditional and independent of the two ordinary inputs needed by the eventual determinant count.
