# Actual gradient-divisible column losses from original coefficient and derivative height bounds

Source: companionT1.7 and the prime-by-prime loss in the global surface determinant. All original columns and actual derivative values are retained.

PrimeDivisorLogBudget proves that for any nonzero actual integer z and any finite set S of distinct primes dividing z, sum_(p in S) log(p)<=log(natAbs(z)). The proof constructs the actual coprime prime product dividing z and compares its positive absolute value. If every p>=K>0, it proves sum log(p)/p<=log(natAbs(z))/K. Negative z, unit certificates and empty prime sets are included.

WeightedExceptionalPrimeFibres proves the actual weighted exceptional-column budget by swapping the finite sums over primes and columns. Every exceptional event B(p,j) need only imply p divides a chosen nonzero integer certificate z_j. It proves sum_p card{j:B(p,j)}*log(p)/p <= (sum_j log(natAbs(z_j)))/K. Cardinalities are expressed intrinsically so the result is independent of predicate decision instances. When the actual certificate values satisfy natAbs(z_j)<=A*H^m with A>0,H>=1, it derives the explicit bound card(columns)*(log(A)+m*log(H))/K.

P3HomogeneousDerivativeHeight proves actual homogeneous polynomial evaluation bounds using the exact degree-d monomial family. If every original coefficient has absolute value<=A, every coefficient of every actual partial derivative has absolute value<=d*A. It proves the derivative value bound natAbs(eval(v,partial_k P)) <= card(Index(d-1))*(d*A)*H^(d-1) for actual height-H integer points. Coefficient cancellation, zero coefficients, d=0 and the exact degree drop are handled internally; no derivative-height bound is supplied.

P3CanonicalGradientPrimeLoss applies those generic budgets to the literal unassigned columns of checkpoint599's canonical classifier. An unassigned original zero has every derivative value divisible by p. The weighted loss is therefore controlled by any actual nonzero partial derivative at each point. It proves the value-specific bound, the height-bound version, and the bound using only the actual homogeneous degree, original coefficient bound and point heights. Its final smooth_points_loss theorem internally selects a nonzero derivative at each original nonsingular point. The resulting loss is at most card(columns)*(log(card(Index(d-1))*(d*A))+(d-1)*log(H))/K. Original columns with bad reduction remain in the determinant; their exact weighted contribution is controlled instead of discarded.
