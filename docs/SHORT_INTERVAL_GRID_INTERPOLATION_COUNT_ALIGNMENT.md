CommonGridMonomialDeterminant defines the actual normalized and integer evaluation matrices for selected total-degree monomials at common-denominator grid points z/N. Multiplying each actual monomial row by its exact denominator power gives the exact determinant identity det(integer matrix)=N^(sum actual degrees)*det(normalized matrix). The actual degree sum is at most k*n. The nonzero integer determinant has absolute value at least one, so a strictly smaller normalized determinant after this clearing is proved zero. The statement does not assume vanishing or an arithmetic gap.

Only this explicit numerical smallness inequality remains a hypothesis; all Taylor, derivative, degree and integer determinant estimates are proved.
