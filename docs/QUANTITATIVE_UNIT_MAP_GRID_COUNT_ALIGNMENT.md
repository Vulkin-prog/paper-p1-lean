UnitIntervalSubdivision constructs the actual floor index and the actual interior midpoint of each of M subintervals of the open unit interval. Every parameter belongs to an index below M, every center stays in the smooth domain, and its assigned parameter is within 1/M of that center. This retains all endpoint conventions and does not assume a finite interval cover.

UnitMapGridPointCount takes M=ceil(L), constructs the actual finite subdivision and actual point populations in each member, applies the previously proved local grid interpolation count, and sums those actual cardinalities. The numerical smallness inequality, interval choice and interval-cover cardinality are now all internal. The generic transfer retains its explicit all-polynomial zero-count argument.

ActualLocalUnitMapGridCount removes that remaining zero-count argument in the actual geometric specialization. For every point of an irreducible real curve inside the open unit box, outside the internally constructed joint exceptional set and with 1<=k<degree(P), it constructs a genuine smooth injective map with positive affine coordinate, the actual curve equation and prescribed midpoint. A second theorem constructs the genuine finite exceptional set with its exact D^2*(30*(n+1)^2+3*(k+1)^6) natural-convention budget and supplies these maps at every remaining point.
