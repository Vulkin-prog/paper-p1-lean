This checkpoint closes local bounded-jet map existence through all strictly bounded nonexceptional points, not the controlled global number of maps.

ShortCenteredAffineSegment constructs an actual admissible segment through a point lying in two open real intervals. It chooses a positive margin delta, a positive scale c<=1 with c<=delta/(2(r+1)), and a center offset u such that theta(1/2)=x_0. The entire affine image theta((0,1)) stays in the second interval and at least delta from both endpoints of the first interval. The original point lies strictly inside (u,u+c). All margins and scales are conclusions, obtained from explicit finite minima of the actual endpoint distances.

BoxedLocalUnitGraphMaps first proves that any actual smooth graph point whose two coordinates have absolute value strictly below1 has an actual smaller parameter interval with the same strict bound on both component functions. Coordinate continuity and the finite neighborhood intersection construct this bounded interval. The centered-segment construction and the internally proved affine parametrization theorem then produce an actual C-infinity two-component map on (0,1), with unit actual component jets of every order0 throughr, preserving the original curve equation and mapping parameter1/2 exactly to the original graph point. Its image covers a whole open graph segment around that point, rather than only the point itself.

At every actual point z of a positive-degree irreducible real plane curve with |z_i|<1 and outside the order-(r+1) graph-control locus, the graph piece, orientation, bounded interval, margin, affine scale and resulting unit-jet curve map are all internally constructed. The final theorem constructs a genuine finite set E with exact control-locus membership and at most30 deg(P)^2(r+2)^2 points, before every such z. Each z outside E has a C-infinity map with the actual unit derivative bounds and exact middle-parameter value z. No chart, smooth extension, bounded segment, derivative magnitude, scale or margin is supplied as a geometric input.

These are local unit-jet maps through every bounded nonexceptional point, with coverage of a local graph segment. The theorem does not bound the global number of maps, cover a whole connected curve component by one graph, supply a controlled finite global parametrization, prove the final sharp plane count or higher-dimensional projection.
