# Finite Rolle zero populations and a recursive Chebyshev criterion

Sources rechecked: main13.4, main_sections/pair_rigidity.tex211-226; primary BCN arXiv2302.04209v2 Sections2-5, https://arxiv.org/pdf/2302.04209v2. This is a preparatory recursive-pivot criterion, not a proof of the full source theorem.

The finite zero-counting core for the real-analytic BCN route is now internally proved. FiniteRolleZeros constructs one actual derivative zero in every gap between consecutive points of any given finite zero population inside an open real interval. The construction uses the increasing finite enumeration and Rolle theorem, proves the constructed derivative zeros are distinct and retains their interval membership. It needs only continuity of the original function on that interval. There is no assumed finiteness or cardinality bound for the whole zero set.

The finite derivative inequality and its iteration are proved separately. A boundk on all finite derivative-zero populations yields at mostk+1 original zeros. If every iterated derivative through ordern is continuous and the actualnth derivative is nowhere zero, every finite original zero population has cardinality at mostn. The casesn=0, empty populations and arbitrary open intervals are included.

RecursiveChebyshev gives a concrete recursive pivot criterion. For an actual finite family, divide its tail by the first function and differentiate. Admissible requires differentiability of the current functions, nonvanishing of the current first function, and the same conditions on the smaller normalized derivative family. These are actual regularity and pivot properties; no zero-count estimate is a field or premise. The normalized finite-sum identity and its actual derivative are proved, with all nonvanishing divisions and interval restrictions explicit. Induction using the finite Rolle construction proves every combination with nonzero coefficient vector has fewer zeros than the family size. Evaluation at any sufficiently large actual finite set is therefore injective, and vanishing there forces every coefficient to be zero.
