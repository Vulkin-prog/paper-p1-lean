BoundedPrimitiveLinearCombination constructs an actual primitive linear combination of any finite generating coordinate family in a characteristic-zero finite field extension L/K. It takes every pair of distinct actual embeddings into an algebraically closed field. Their actual coordinate-difference vector is nonzero because the original coordinates generate the entire algebra. There are at most D^2 such vectors, where D is the actual extension degree. The internally proved bounded moment-curve construction supplies one nonnegative integer coefficient vector avoiding all those differences. The resulting actual linear combination has distinct values under all embeddings and is therefore primitive by the pinned primitive-element embedding criterion. Its minimal polynomial has actual degree D. Every coefficient is at most ((n-1)*D^2+1)^(n-1). No primitive-element choice, conjugate-separation condition or bounded-coefficient hypothesis is supplied.
