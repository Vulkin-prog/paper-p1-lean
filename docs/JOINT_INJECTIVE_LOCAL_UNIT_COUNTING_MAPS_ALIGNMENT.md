UnitGraphMonomialPieceCount proves that every actual unit-slope graph piece carries an internally constructed smooth nowhere-zero polynomial tangent scale, in either orientation. Its actual positive affine reparametrizations retain such a scale. The exact scaled Wronskian/Chebyshev theorem then gives the strict every-polynomial image-point bound below the actual monomial-family size on those affine graph maps, whenever the original graph avoids the concrete monomial Wronskian exceptions. UnitSlopePieceRestriction proves that actual unit-slope graph data, all derivative signs, C-infinity regularity and actual distance bounds survive restriction to a smaller open interval. JointGraphChebyshevExceptions constructs the genuine common exceptional locus: the order-(r+1) graph-control locus together with the complete singular-plus-monomial-Wronskian locus for degree capk. For every actual irreducible real plane polynomial and k<deg(P), a finite set with exactly that membership is constructed and satisfies E.card<=deg(P)^2*(30(r+2)^2+3(k+1)^6). Both original avoidance conditions follow explicitly from the common one.

JointLocalUnitCountingMaps assembles the actual constructions. At every curve point z with |z_i|<1 and outside that common set, it constructs the normalized unit-slope graph, shrinks it to avoid the whole common finite set, selects an actual bounded centered affine segment, and produces a C-infinity curve map psi:(0,1)->R^2. Every actual component jet of every order0 throughr has magnitude at most1. The whole image lies on P=0 and avoids the common locus, and psi(1/2)=z exactly. A selected original coordinate is explicitly affine with strictly positive slope; the actual point map is proved injective on (0,1). Thus the conclusion retains a nondegenerate actual graph map.

The same actual map is selected before every tested nonzero Q of degree at mostk and every finite distinct image-point population S on which Q vanishes. Each such S has size strictly below the actual full monomial-family size mu, which is at most(k+1)^2. The unit-jet and zero-count conclusions hold simultaneously on that chosen injective map; they are not separate existential choices. The final theorem constructs the common finite E before every starting point and all those map/polynomial/population choices. No trajectory, chart, margin, scale, derivative bound or zero-count target is supplied as an unproved geometric premise.

This closes simultaneous actual local unit-jet and all-polynomial counting maps.
