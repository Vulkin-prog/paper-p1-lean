TernaryPolynomialHilbert proves the exact genuine Hilbert polynomial of the three-variable polynomial grading from the actual homogeneous-piece dimensions. Its quadratic coefficient is one half. LinearHilbertParameterDependence compares these actual pieces with those of any actual graded algebra with a genuine linear Hilbert polynomial. HomogeneousFiniteParameterDescent constructs an actual homogeneous relation in the kernel of a noninjective finite linear polynomial evaluation. Homogeneous linear normalization of the actual kernel quotient then reduces the parameter family by one. The actual quotient lift back to the original algebra is finite by the original finite evaluation, and the lifted parameters are genuinely homogeneous of degree one. This works for every finite number of parameters, and preserves the same target algebra throughout the descent.

FiniteLinearCurveImageNormalization applies this descent inductively to an actual graded algebra embedded injectively and compatibly with scalars into an actual graded algebra with genuine linear Hilbert growth. Families of zero, one or two parameters are padded by zeros with an actual polynomial factorization proving finiteness. Thus the finite linear coordinate image has a genuine two-parameter normalization without assuming any Hilbert polynomial for that image. If the image algebra is a domain, the previously proved two-variable Hilbert existence theorem constructs its genuine actual quotient Hilbert polynomial.

The image polynomial, quotient algebra, grading and homogeneous-piece populations are all the actual existing objects.
